# 🟣 Portfólio — Williams

Portfólio pessoal desenvolvido com **React + Vite**, apresentando minha trajetória como estudante de **Informática para Internet no IFRN – Campus Caicó** e desenvolvedor web em formação.

🔗 **Acesse online:** [DevWil-io.vercel.app](https://DevWill-io.vercel.app)

---

## ✨ Sobre o projeto

Um portfólio moderno, responsivo e com tema claro/escuro, criado para apresentar minhas habilidades, projetos e evolução na programação. O design usa uma paleta roxa, fundo aurora animado e micro-interações suaves.

### 🎯 Destaques

- 🌗 **Tema claro/escuro** com persistência no `localStorage`
- 🌌 **Fundo aurora animado** feito com CSS puro (blobs em movimento)
- 🎬 **Animações suaves** de entrada (reveal on scroll com `IntersectionObserver`)
- 📱 **100% responsivo** — mobile, tablet e desktop
- 🎨 **Paleta roxa** consistente com gradientes modernos
- ⬆️ **Botão "voltar ao topo"** flutuante
- 📅 **Timeline de trajetória** alternada
- 🕐 **Sessão "Agora"** com foco atual de estudos
- 🖼️ **Cards de projeto** com screenshot, tags e links
- ♿ **Acessível** — respeita `prefers-reduced-motion` e navegação por teclado
- 🔍 **SEO + Open Graph** — preview bonito ao compartilhar o link

---

## 🛠️ Tecnologias utilizadas

- **React 18** — biblioteca de UI
- **Vite** — build tool rápido
- **JavaScript (ES6+)** — sem TypeScript
- **CSS puro** — sem frameworks, sem Tailwind
- **Google Fonts** — Inter + Space Grotesk
- **Simple Icons CDN** — ícones reais das tecnologias

## 🚀 Como rodar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org) 18+ instalado
- npm ou yarn

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/DevWill-io/SEU-REPO.git

# 2. Entre na pasta
cd SEU-REPO

# 3. Instale as dependências
npm install

# 4. Rode em modo de desenvolvimento
npm run dev
